# ELITE Home & Auto Services

Premium React/Vite website for ELITE Home & Auto Services, Abu Dhabi.

## Commands

```bash
npm install
npm run dev
npm run build
npm run preview
```

## Stack
React, Vite, TypeScript, Tailwind CSS, GSAP ScrollTrigger, Lenis, Framer Motion-ready architecture, Lucide icons, React Router, React Hook Form and Zod.
